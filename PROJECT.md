# CrOS New Tab — Документация проекта

Кастомизируемая пустая новая вкладка для ChromeOS с автоматической адаптацией под системную цветовую гамму.

---

## Контроль версий (Git / GitHub)

При каждом завершении работы над проектом изменения фиксируются и отправляются в репозиторий на GitHub:

```bash
git add .
git commit -m "Ваше описание изменений"
git push origin main
```

Или через скрипт:
```bash
./scripts/sync-github.sh "Ваше описание изменений"
```
