## 🎯 Архитектура и особенности проекта

### 1. Адаптация под ChromeOS (Стиль и цвета системы)
* **Автоматическое отслеживание темы ChromeOS:** через медиа-запрос `@media (prefers-color-scheme: dark)` и слушатель событий в реальном времени `ThemeManager`. При переключении темы в системном меню Chromebook (Быстрые настройки / Ночной режим) интерфейс расширения мгновенно перекрашивается без перезагрузки страницы.
* **Материальная палитра (Material You / Material Design 3):** Поддержка системного синего цвета CrOS (`#1a73e8` / `#8ab4f8`), а также акцентов: бирюзовый (Teal), фиолетовый (Purple), коралловый (Rose), изумрудный (Emerald).
* **Системная типографика:** Google Sans / Roboto / system-ui, аутентичные радиусы скругления (ChromeOS rounded corners) и тени Elevation.

### 2. Модульная архитектура интеракций
Любая функция — это независимый изолированный модуль с простым жизненным циклом:
* Каждый модуль реализует интерфейс:
  * `id`: уникальный ключ
  * `name`: название в меню
  * `icon`: иконка/эмодзи
  * `render(container, context)`: отрисовка интерфейса
  * `onPageAction`: доступ к исполнению кода на открытой вкладке через `chrome.scripting`
* Модули регистрируются в едином `ModuleRegistry`, сохраняют свое состояние в `chrome.storage` и могут включаться/отключаться пользователем на лету в настройках.

### 3. Встроенные модули «из коробки»
1. **📝 Быстрые заметки (`quick-notes`)**: блокнот с мгновенным автосохранением, разделенный на глобальные заметки и заметки, привязанные к текущему сайту.
2. **⚡ Интеракция со страницей (`page-actions`)**: копирование Markdown-ссылок в 1 клик, ночной фильтр, статистика текста (слова, знаки, время чтения), подсветка ссылок.
3. **🎨 Стиль & Палитра (`color-inspector`)**: управление темами, акцентами и пипетка для считывания цветовой палитры любого сайта.
4. **🧩 Конструктор модулей (`user-snippets`)**: визуальный конструктор прямо в расширении! Позволяет создавать новые модули и кнопки с вашим JavaScript-кодом без редактирования исходников.

## 🛠️ Как добавить новый модуль интеракции (за 3 минуты)

### Шаг 1: Создайте файл модуля
Скопируйте `modules/template/module-template.js` в новую папку, например `modules/my-tool/index.js`:
```javascript
export const myToolModule = {
  id: 'my-tool',
  name: 'Мой инструмент',
  icon: '🚀',
  description: 'Пользовательский модуль для обработки страниц',
  category: 'interaction',
  defaultEnabled: true,

  async render(container, context) {
    container.innerHTML = `
      <button class="cros-btn cros-btn-primary" id="my-btn">
        Запустить действие
      </button>
      <div id="output" style="margin-top:8px;"></div>
    `;

    container.querySelector('#my-btn').addEventListener('click', async () => {
      // Исполнение любого скрипта на текущей вкладке:
      const result = await context.registry.executeInActiveTab(() => {
        return document.title.toUpperCase();
      });
      container.querySelector('#output').textContent = `Заголовок: ${result}`;
    });
  }
};
```

### Шаг 2: Зарегистрируйте в `modules/index.js`
Откройте `modules/index.js` и добавьте 2 строчки:
```javascript
import { myToolModule } from './my-tool/index.js';

registry.register(myToolModule);
```

### Шаг 3: Перезагрузите расширение в Chrome
Откройте `chrome://extensions` и нажмите значок обновления 🔄. Новый модуль готов и доступен во всех вкладках и боковой панели!

## 🚀 Установка расширения на Chromebook

1. Откройте браузер Chrome.
2. В адресной строке перейдите на страницу: `chrome://extensions`.
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите директорию:
   `/home/otheos/chromebook-modular-extension`  
   *(В файловом менеджере ChromeOS Linux-файлы доступны во вкладке «Файлы Linux»)*.
6. Расширение установлено и готово к работе!
