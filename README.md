# 🖥️ CrOS New Tab

> **Удобное и эстетичное расширение для Google Chrome, превращающее новую вкладку в полноценный рабочий стол для ChromeOS.**

---

### 💡 О проекте

Операционная система ChromeOS изначально не поддерживает привычные виджеты на рабочем столе. Из этой особенности родилась простая, но практичная идея — превратить сам браузер в уютное, функциональное и живое рабочее пространство.

Каждая новая вкладка открывается не пустой страницей, а лаконичным рабочим столом, который гармонично дополняет систему и радует глаз.

---

### 🚀 Установка

1. Откройте страницу `chrome://extensions` в Google Chrome.
2. Включите тумблер **«Режим разработчика»** в верхнем правом углу.
3. Нажмите **«Загрузить распакованное расширение»** и укажите директорию проекта.
