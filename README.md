# 🖥️ CrOS New Tab (v0.4.0)

> **Удобное и эстетичное расширение для Google Chrome, превращающее новую вкладку в полноценный рабочий стол для ChromeOS с виджетами, интеграцией сервисов Google, погодой и защитой от случайного закрытия.**

---

## 💡 О проекте

Операционная система ChromeOS изначально не поддерживает размещение привычных виджетов на рабочем столе. Из этой особенности родилась простая, но практичная идея — превратить новую вкладку браузера в уютное, функциональное и живое рабочее пространство.

Каждая новая вкладка открывается не пустой страницей, а полноценным адаптивным рабочим столом в стиле Material 3, который гармонично дополняет ChromeOS и сохраняет все настройки между сессиями.

---

## 🚀 Установка

1. Откройте страницу `chrome://extensions` в Google Chrome / Chromium.
2. Включите тумблер **«Режим разработчика»** (Developer mode) в верхнем правом углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и укажите корневую директорию проекта.
4. Откройте новую вкладку — перед вами рабочий стол CrOS New Tab!

## 🆕 Что нового в v0.4.0

### Поиск
- Убран значок «/» из строки быстрого поиска.
- **Рекомендации поиска** на основе Google-запросов пользователя: из истории браузера (`chrome.history`, новое разрешение `history`) и собственной истории запросов поля. Ранжирование по совпадению начала, частоте и свежести; навигация стрелками, `Esc` закрывает список.
- Любой запрос и адрес из быстрого поиска открывается **в новой вкладке**.

### Часы и раскладка
- Часы теперь сверху по центру, поле поиска расположено под ними; положение поиска вычисляется от нижнего края часов, поэтому они не перекрываются при любом размере.
- **Дизайны часов** (Настройки → Вид → Часы): шесть готовых пресетов — Классика, Минимал, Жирные, Моно, Серифы, Компакт.
- **Гибкая настройка**: 12/24-часовой формат, секунды, дата, фон-карточка, размер, толщина, скругление, шрифт, цвет. Кнопка сброса своих настроек. Выбор сохраняется в `state.clock`.

### Ярлыки
- **Закрепление ярлыков** через контекстное меню (ПКМ → «Закрепить» / «Открепить»): закреплённый ярлык нельзя перемещать; индикатор закрепления не отображается.

### Исправления
- Больше не возвращаются виджеты по умолчанию при открытии новой вкладки: миграция сохраняла версию хранилища 4, но принимала только 3 и каждый раз заново подставляла стандартные виджеты. Теперь показывается только то, что настроил пользователь (в т. ч. пустой список).
- Панель настроек больше не закрывается после каждого нажатия — только при клике вне панели (диалоги и контекстные меню не считаются «вне»).

### Прочее
- Удалена кнопка полного экрана и пункт «Полный экран» из контекстного меню рабочего стола.

## ✨ Возможности версии 0.4.0

### 1. Полноценный рабочий стол и модульные виджеты
- **Сетка рабочего стола**: свободное перемещение виджетов и ярлыков (drag & drop), автосохранение координат в `chrome.storage.local`.
- **Изменение размеров (ResizeObserver)**: гибкая настройка размеров карточек виджетов.
- **Встроенные виджеты**:
  - **Цифровые часы и дата**: гармоничные часы в стиле Material 3 с адаптивной типографикой.
  - **Заметка (Note)**: быстрые текстовые заметки с сохранением содержимого.
  - **Список задач (Todo)**: интерактивный чек-лист дел.
  - **Обратный отсчет (Countdown)**: таймер до важного события.
  - **Веб-фрейм (Embed)**: встраивание сторонних страниц и дашбордов через iframe.
- **Кастомизация и оформление**:
  - Динамическая генерация гармоничной палитры Material 3 (`newtab.js`), интерактивный цветовой круг, слайдер яркости и системная пипетка (EyeDropper API).
  - Свои обои: загрузка локального изображения или ссылка из сети, настраиваемое затемнение фона.
  - Полноэкранный режим (F11, опция автовхода по первому клику; отдельная кнопка на панели убрана).
  - Быстрый поиск: активация при начале ввода текста.

### 2. Интеграция с сервисами Google
- **Авторизация через OAuth 2.0 (`chrome.identity.launchWebAuthFlow`)**:
  - Пользователь может ввести собственный OAuth 2.0 Client ID в настройках расширения.
  - Понятная пошаговая инструкция по созданию Client ID в Google Cloud Console.
  - Поддержка тестового mock-режима для автономной работы и тестирования без авторизации.
- **API-виджеты**:
  - **Google Calendar**: список ближайших предстоящих событий из календаря пользователя.
  - **Gmail**: счетчик непрочитанных писем и список последних входящих сообщений.
  - **Google Drive**: список последних измененных файлов с прямыми ссылками на открытие.
- **Новости и сервисы**:
  - **Google News RSS**: сводка актуальных новостей через RSS-ленту Google.
  - **Ярлыки сервисов**: быстрый доступ к Google One, Google Photos, Google Keep, YouTube и др.

### 3. Погода Open-Meteo (без API-ключа)
- Бесплатный и надежный прогноз погоды на базе API Open-Meteo:
  - Автоматическое определение по геолокации или ручной ввод любого города мира (геокодирование Open-Meteo Geocoding API).
  - Текущая температура, скорость ветра, погодные условия по международным кодам WMO (ясно, облачно, дождь, снег, гроза).
  - Краткий прогноз на несколько дней вперед.
  - Надежное оффлайн-кэширование и устойчивость к сбоям сети.

### 4. Защита от случайного закрытия (Anti-Close Protection)
- **Подтверждение закрытия (`beforeunload`)**:
  - При попытке закрыть вкладку рабочего стола браузер запрашивает подтверждение, предотвращая случайную потерю рабочего пространства.
  - Учитывает состояние `navigator.userActivation.hasBeenActive` — не блокирует вкладку при открытии без действий пользователя.
  - Ожидаемые действия (переход по ярлыку, поиск) выполняются без лишних диалогов.
  - Опция защиты легко включается и выключается в панели настроек (по умолчанию включена).
- **Фоновый страж (Service Worker в `background.js`)**:
  - Отслеживает события закрытия вкладок и окон (`chrome.tabs.onRemoved`, `chrome.windows.onRemoved`).
  - При закрытии последней вкладки рабочего стола или окна мгновенно переоткрывает окно рабочего стола.

## 🛡️ Честные ограничения браузерных расширений

Chromium имеет строгую модель изоляции безопасности. Чтобы пользователи четко понимали границы возможностей расширения, ниже приведен перечень того, что расширение может и чего не может делать:

### ✅ Что расширение МОЖЕТ делать:
1. **Запросить подтверждение перед закрытием вкладки (`beforeunload`)**: браузер покажет стандартный диалог подтверждения, если пользователь совершил хотя бы одно действие на странице.
2. **Закрепить вкладку (`pinned: true`)**: у закрепленной вкладки отсутствует кнопка крестика («X»), что исключает случайный клик мыши.
3. **Отследить закрытие вкладок и окон в фоне**: через события `chrome.tabs.onRemoved` и `chrome.windows.onRemoved` в `background.js`.
4. **Автоматически переоткрыть вкладку или окно рабочего стола**: если закрывается последняя вкладка рабочего стола, пока процесс браузера запущен.
5. **Заблокировать удаление расширения**: с помощью корпоративных политик Chrome Enterprise.

### ❌ Что расширение НЕ МОЖЕТ делать (ограничения безопасности Chromium):
1. **Перехват системных шорткатов**: Расширения не могут заблокировать сочетания клавиш `Ctrl+W`, `Ctrl+Shift+W`, `Ctrl+Q`, `Ctrl+Shift+Q` или `Alt+F4` на уровне клавиатурных хуков — оконный менеджер Chromium обрабатывает их до передачи странице или расширению.
2. **Кастомизация текста системного диалога**: Расширение не может изменить стандартный текст браузера в диалоге `beforeunload` (*«Покинуть сайт? Внесенные изменения могут не сохраниться»*).
3. **Вызов подтверждения без жеста пользователя**: Если пользователь только что открыл вкладку и не кликнул по ней ни разу, Chromium проигнорирует обработчик `beforeunload` (требование спецификации HTML User Activation).
4. **Синхронная отмена закрытия вкладки в API**: В методе `chrome.tabs.onRemoved` нет метода `preventDefault()`. Вкладка закрывается безвозвратно, расширение может лишь создать *новую* взамен закрытой.
5. **Воскрешение после полного закрытия браузера**: При нажатии `Ctrl+Shift+Q` (полный выход из Chrome) или выключении компьютера кнопкой питания процесс браузера завершается вместе с Service Worker. Запустить браузер заново расширение самостоятельно не может — для этого требуется режим Kiosk Mode или системный автозапуск ОС.

## 🏢 Развертывание в ChromeOS Kiosk Mode и Enterprise Management

Для абсолютной блокировки интерфейса и предотвращения закрытия рабочего стола на корпоративных устройствах или терминалах ChromeOS используется **Kiosk Mode** и корпоративные политики Chrome Enterprise (Google Admin Console).

### 1. ChromeOS Kiosk Mode (Режим киоска)
Режим киоска запускает расширение на весь экран без адресной строки, панели вкладок и кнопок управления окном:
- **`DeviceLocalAccounts`**: настройка локального киоск-аккаунта на устройстве ChromeOS.
- **`AutoLaunchKioskApp`**: автоматический запуск выбранного расширения/приложения сразу после загрузки ChromeOS без экрана входа.

Пример фрагмента конфигурации политики Kiosk Mode:
```json
{
  "DeviceLocalAccounts": {
    "Value": [
      {
        "account_id": "kiosk_cros_newtab@managedchrome.com",
        "type": 2,
        "kiosk_app": {
          "app_id": "<EXTENSION_ID>"
        }
      }
    ]
  },
  "AutoLaunchKioskApp": {
    "Value": "<EXTENSION_ID>"
  }
}
```

### 2. Политики принудительной установки и автозапуска (Chrome Enterprise Policies)
Если ChromeOS используется в стандартном многопользовательском режиме, но требуется зафиксировать CrOS New Tab:

- **`ExtensionInstallForcelist`**: принудительная установка расширения. Пользователь не может отключить или удалить его:
  ```json
  {
    "ExtensionInstallForcelist": {
      "Value": [
        "<EXTENSION_ID>;https://clients2.google.com/service/update2/crx"
      ]
    }
  }
  ```

- **`RestoreOnStartup`** и **`RestoreOnStartupURLs`**: принудительное открытие вкладки рабочего стола при запуске браузера:
  ```json
  {
    "RestoreOnStartup": {
      "Value": 4
    },
    "RestoreOnStartupURLs": {
      "Value": [
        "chrome-extension://<EXTENSION_ID>/newtab.html"
      ]
    }
  }
  ```

- **`URLBlocklist`** и **`URLAllowlist`**: ограничение перехода по внешним ссылкам для создания изолированного контура (Walled Garden):
  ```json
  {
    "URLBlocklist": {
      "Value": ["*"]
    },
    "URLAllowlist": {
      "Value": [
        "chrome-extension://<EXTENSION_ID>/*",
        "https://*.google.com/*",
        "https://api.open-meteo.com/*"
      ]
    }
  }
  ```

## 🔒 Безопасность и конфиденциальность

- **Чистый код**: без внешних сборщиков, без фреймворков, без CDN-скриптов. Вся кодовая база работает автономно.
- **Client ID**: OAuth 2.0 Client ID является публичным идентификатором клиента расширения в Google Identity; клиентские секреты (Client Secret) никогда не хранятся в коде.
- **Изоляция данных**: все пользовательские настройки, токены и заметки хранятся исключительно в защищенном локальном хранилище браузера `chrome.storage.local`.
