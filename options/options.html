⚡ Как добавить свой модуль интеракции

Расширение спроектировано так, чтобы добавление нового функционала занимало считанные минуты.

Способ 1: Через код (рекомендуемый для сложных расширений)
  1. Создайте файл модуля, например: modules/my-action/index.js по шаблону из modules/template/module-template.js.
  2. Импортируйте его в modules/index.js и вызовите registry.register(myAction).
  3. Обновите расширение в chrome://extensions. Модуль сразу появится в меню!
Способ 2: Без кода через встроенный «Конструктор модулей»

Откройте popup или боковую панель, перейдите на вкладку «Конструктор модулей» и вставьте любой JavaScript код для выполнения на странице.
